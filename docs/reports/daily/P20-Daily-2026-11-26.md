**8. Things learned / notes for the thesis**

- npm lockfile v2/v3 lists packages for every platform (`os`/`cpu` fields), not just the installed ones. A scanner reading the lockfile therefore sees more packages than `npm ls` (npm docs, package-lock.json, accessed 2026-11-26).
- npm aliases (`"x": "npm:real@1.0.0"`) store the real name in the entry's `name` field. A scanner that uses the folder name misses advisories.
- Writing tests first caught two real bugs before the code was used anywhere.
